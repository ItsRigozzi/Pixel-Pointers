Bienvenido a **Pixel Pointers**, un videojuego educativo en 2D desarrollado en **Godot Engine**. Con una perspectiva *top-down* inspirada en RPGs clásicos como Pokémon, este juego te sumerge en una aventura interactiva donde el aprendizaje se mezcla con la exploración y el cumplimiento de misiones.

---

## ✨ Características Principales

- **🗺️ Perspectiva Top-Down 2D**: Explora un mundo vibrante con un estilo visual clásico, recorriendo distintos pueblos, rutas y edificios.
- **📈 3 Niveles de Dificultad Progresiva**: Avanza a través de tres niveles principales, cada uno con desafíos más complejos que pondrán a prueba lo aprendido.
- **📜 Sistema de Quests y Misiones**: Interactúa con diversos NPCs (magos, profesores, etc.) para recibir misiones educativas, responder preguntas, resolver puzzles y avanzar en la historia.
- **⚔️ Jefes de Nivel y Exámenes**: Enfréntate a jefes y muros de exámenes que evaluarán tus conocimientos antes de permitirte avanzar al siguiente nivel.
- **🎓 Enfoque Educativo**: Diseñado para enseñar y reforzar conceptos de manera lúdica, obteniendo recompensas y medallas por tu progreso.

---

## 🚀 Requisitos y Ejecución

- **Motor**: Desarrollado en [Godot Engine](https://godotengine.org/).
- **Lenguaje**: GDScript.

### Cómo jugar o editar localmente:

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/tu-usuario/Pixel-Pointers.git
   ```
2. **Abrir en Godot**:
   - Abre Godot Engine.
   - Selecciona **Importar** y busca el archivo `project.godot` en la carpeta que acabas de descargar.
3. **Ejecutar**:
   - Una vez cargado el proyecto en el editor, presiona el botón de **Play** (Reproducir) en la esquina superior derecha o pulsa `F5` para iniciar la aventura.

---

## 🛠️ Estructura del Proyecto

El repositorio incluye todos los *assets*, *scripts* y *escenas* (.tscn) necesarios para el funcionamiento del juego:
- **Mapas/Mundos**: `pueblo_principal`, `mapa_nivel_2`, `mapa_nivel_3`, `ruta_k`, además de interiores de casas y tiendas.
- **Personajes (Jugador y NPCs)**: `jugador`, `mago`, `profesores`, `jefe_nivel`, entre otros.
- **Sistemas UI**: Menú principal, menús de pausa, cajas de diálogo interactivas, e interfaces de vidas/corazones.
